Карта Yoobi — Таджикистан на вашем компьютере
=============================================

Как поставить на диск C (Windows)
1. Распакуйте архив в папку C:\Yoobi (правой кнопкой по архиву → «Извлечь всё…» →
   в поле пути напишите C:\Yoobi → «Извлечь»).
2. Откройте папку C:\Yoobi\yoobi-map и дважды щёлкните «Открыть карту.bat».
   Откроется браузер с картой. Чёрное окно — это сервер карты: не закрывайте его,
   пока пользуетесь картой. Закрыли окно — карта перестанет работать до следующего запуска.
3. Если Windows спросит «Защитник Windows предотвратил запуск» — нажмите
   «Подробнее» → «Выполнить в любом случае» (файл запускает только локальный сервер).

Интернет не нужен: тайлы всей страны, поиск по адресам, шрифты и код — в этой папке.
Нужен современный браузер: Chrome, Edge, Firefox или Яндекс.Браузер.

macOS: дважды щёлкните start.command (нужен Python 3). Linux: ./start.sh.

Что внутри
- index.html — карта; src/ — код карты; tiles/ — тайлы (части по 1 МБ);
  search.json — поиск адресов и мест; fonts/, sprites/ — шрифты и значки; lib/ — MapLibre.
- server.ps1 — сервер для Windows (PowerShell), «Открыть карту.bat» — его запуск.

Сообщения «Сообщить об изменении» в этой версии сохраняются только в этом браузере.

Обновлённая карта — новая папка с тем же устройством: замените старую.
