Сюда кладут GeoJSON с тем, чем можно пользоваться на карте: съёмкой курьеров, выгрузкой из
Every Door или OsmAnd, данными, полученными по лицензии. Точки, линии и контуры с тегами OSM
в `properties` (`amenity`, `name`, `building`, `highway`, `bridge`…), плюс `source` и `date`.
Формат и правила — в `scripts/corrections.py`; файлы подхватывает сборка (`build-tiles.sh`).
Данные чужих справочников (2ГИС, Яндекс, Google) без лицензии на хранение и показ сюда не кладут.
